# The fonts in this folder

All seven are released under the SIL Open Font License 1.1, whose full text is in `OFL.txt`. They are included unmodified so the pack runs end to end; the OFL allows that as long as each copy keeps its copyright notice and the licence. Each file's own notice is in its name table and is copied here.

|---|---|---|

| `DMMono-Regular.ttf` | DM Mono 1.000 | Copyright 2020 The DM Mono Project Authors (https://www.github.com/googlefonts/dm-mono) |

| `Newsreader-VF.ttf` | Newsreader 1.003 | Copyright 2020 The Newsreader Project Authors (http://github.com/productiontype/Newsreader) |
| `Fraunces-VF.ttf` | Fraunces 1.000 | Copyright 2020 The Fraunces Project Authors (github.com/undercasetype/Fraunces) |

Hanken Grotesk and DM Mono are the typefaces of my personal kit. IBM Plex Sans is the typeface IBM's Carbon design system is set in. Inter, Source Serif 4, Newsreader and Fraunces each have an optical-size axis: their designers drew a different version of the letters for small and large sizes, and `faces.py` reads how the spacing between letters changes along it.

All of them can be downloaded free from Google Fonts. The SHA-256 of each file I measured is in `results-30-october/faces.json`.
