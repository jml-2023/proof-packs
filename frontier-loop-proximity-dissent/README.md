# Frontier Pack — In, Near, and Out of the Loop (`frontier-loop-proximity-dissent`)

Runnable simulation and operating contract behind *In, near, and out of the loop* on [Proof & Judgement](https://jerrylieveld.substack.com).

## Run
```bash
node run.mjs
```

## Limits
Synthetic deterministic simulation calibrated to observed multi-agent interruption and handoff ratios; illustrates governance mechanics rather than human survey data.
