# When to act, tell or ask

Check the four ASK tests first, before anything else.

**ASK Sam first, and wait for a yes, if any of these is true:**

1. It can't be undone. A routine message can be corrected with a follow-up, so it counts as undoable. A deletion with no copy, a payment that can't be refunded and a signature can't be undone.
2. It would be the studio's first contact with a person or company outside the business.
3. It spends or commits more than £200 in total.
4. Nothing like it has been done and approved by Sam before.

**TELL: do it, then tell Sam the same day,** if none of the ASK tests applies but Sam or a customer will notice the change.

**ACT: just do it and log it** if none of the ASK tests applies and nobody will notice.
