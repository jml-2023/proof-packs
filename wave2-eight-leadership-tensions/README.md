# Wave-2 Pack — Eight Leadership Tensions & Agentic UX Canon Auditor (`wave2-eight-leadership-tensions`)

Design-principles markdown auditor behind **Eight arguments I keep having with myself (and five rules I never wrote down)** on *Proof & Judgement*.

## What it tests & proves
1. **Unconditioned virtues vs deciding variables:** Pairs eight classic design-leadership tensions (*explore loosely vs strict gates*, *ship fast vs rework cost*, *encode in scripts vs human eye*, *one default vs expert controls*, etc.) with the deciding variable that resolves each.
2. **Audit your own `PRINCIPLES.md`:** Checks any principles document for five agentic UX laws absent from pre-AI static-screen canons (`0/5` on conventional docs vs `5/5` upgraded).

## Quick start
```bash
node run.mjs
node run.mjs path/to/PRINCIPLES.md
```

## Scope & limits
Generalisable lexical and structural checklist; customize `EIGHT_TENSIONS` and `FIVE_UNWRITTEN_AGENTIC_RULES` in `run.mjs` to match your product's domain vocabulary.
